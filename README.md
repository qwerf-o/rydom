# Сайт «рядом»

Статический сайт: HTML, CSS и JS без сборки.

## Как открыть

Двойной клик по `index.html` — сайт откроется в браузере.

Или через локальный сервер, из папки проекта:

```bash
python3 -m http.server 8080 --directory сайт
```

Потом открыть http://localhost:8080

Для показа лучше открывать через сервер. Если открыть файлом, Chrome может не подгрузить шрифт заголовков, и вместо IF Kica будет Helvetica. Остальное работает и так.

## Что где лежит

- `index.html` и остальные `*.html` — страницы. Тексты правятся прямо в них.
- `css/style.css` — стили. Цвета, шрифты и размеры — в переменных в начале файла (`:root`).
- `js/layout.js` — шапка, меню с выпадающими пунктами, подвал, окна «Срочная помощь» и «Поддержать проект», кнопки «Назад» / «Наверх» / «Продолжить», список страниц для поиска. Всё это правится здесь, один раз на все страницы.
- `js/main.js` — быстрый выход, Esc дважды, поиск, анимации.
- `js/map.js` — карта и фильтры центров.
- `js/tests.js` — вопросы и результаты трёх тестов.
- `js/chat.js` — интерактив «23:40».
- `data/centers.js` — база центров для сайта. Руками не править.
- `data/build_centers.py` — собирает `centers.js` из `данные/centers.json`.
- `fonts/` — IF Kica (заголовки). Основной текст — системная Helvetica Neue.
- `img/` — иконка вкладки и картинка для превью ссылки.

## Что вписать, когда появится

Всё в начале `js/layout.js`:

- `MANAGER_URL` — ссылка на менеджера в Telegram, например `"https://t.me/nickname"`. Пока пусто, кнопки «Написать менеджеру» ведут на страницу `contact.html`.
- `SOCIAL` — ссылки на ВКонтакте, Telegram и Дзен.
- `PAGES` — куда ведёт «Назад», если на страницу пришли не с сайта, и что написано на кнопке «Продолжить» внизу.
- Текст «Куда пойдут деньги» — в блоке `donate` там же.

## Почему «назад» в браузере не возвращает на сайт

Так задумано. Все переходы по сайту не копятся в истории вкладки, и после быстрого выхода кнопка «назад» не вернёт на сайт. Для навигации у сайта своя кнопка «Назад» вверху и внизу каждой страницы. Путь по страницам она помнит только пока открыта вкладка.

## Как обновить базу центров

1. Поправить `данные/centers.json`.
2. Из папки проекта запустить `python3 сайт/data/build_centers.py`.

Скрипт сам уберёт центры с tier «Закрыт», «Юридический риск» и inoagent = yes. Служебные пометки из заметок он тоже уберёт.

Когда центр проверят звонком, впишите дату в поле `checked` (например, `"24.10.2026"`). На карточке появится «Проверено звонком 24.10.2026».

## Фото

Фото лежат в `img/photos/`. Сейчас это ч/б кадры с Unsplash: их можно бесплатно ставить на сайт, откуда какой — в `img/photos/CREDITS.md`.

Чтобы заменить фото на своё, положите файл с тем же именем в `img/photos/`. Фото команды на странице «О нас» пока заглушки: туда нужны настоящие фото Евгении и Ульяны.

## Висячие предлоги

Их убирает `js/main.js` сам: короткие слова (в, с, и, что, на, не…) приклеиваются к следующему слову, тире — к предыдущему. Ничего вручную ставить не нужно, в том числе в новых текстах.

## Шрифты

Заголовки — IF Kica, всегда капсом. В файлах шрифта перепутаны строчные «и» и «й», а у «Ё» нет точек. Поэтому строчными IF Kica не набирать.

## Безопасность — не ломать

- `<title>рядом</title>` и нейтральные `og:` на каждой странице.
- Скрипт `js/main.js` подключён на каждой странице. Без него не работают быстрый выход и Esc.
- Никаких localStorage, cookies, форм с именем и телефоном, рекламных пикселей.
- Адреса убежищ не публикуем.
